# Shipped weapon-move retunes

One ModuleScript per Default (weapon / standalone) move retune, written by the Move Editor's Studio-only
**Tools > Source > Write to source** and installed at boot through `DefaultMoveRegistry.SetShipped`.
A shipped retune is part of what the move is BUILT as: "Reset to default" returns to it, and a live
DataStore override still layers on top of it.

This README only exists so git keeps the folder; Rojo ignores `.md` files.
